Capturas de Selectores CSS

Selector Universal (*)

Regla aplicada: * { margin: 0; padding: 0; box-sizing: border-box; }

Selector de Tipo (body, h1, p)

Regla aplicada: body { font-family: 'Arial', sans-serif; line-height: 1.6; background-color: #f0f8ff; color: #333; }

Selector por Clase

Regla aplicada: .pagina-comics main .comic-card figcaption, .pagina-videojuegos main .videojuego-card figcaption, .pagina-series main .serie-card figcaption, .pagina-deportes main .deporte-card figcaption { background-color: #4682b4; padding: 0.5rem; border-radius: 5px; }

Selector por ID

Regla aplicada: #titulo-principal { color: #ff6347; } #titulo-comics { color: #ff4500; } #titulo-deportes { color: #32cd32; } #titulo-series { color: #8a2be2; } #titulo-videojuegos { color: #ffffff; }

Selector de Atributo (img[alt])

Regla aplicada: img[alt] { border: 2px solid #ccc; border-radius: 5px; }

Selector de Lista (ul li)

Regla aplicada: ul li { list-style-type: square; }

Selector Descendiente (nav ul li a)

Regla aplicada: nav ul li a { font-weight: bold; }

Selector Hijos Directos (main > section)

Regla aplicada: main > section { border: 2px solid #1e90ff; }

Selector Hermano Adyacente (h3 + ul)

Regla aplicada: h3 + ul { background-color: #f5f5f5; padding: 0.5rem; border-radius: 5px; }

Selector Hermano General (h3 ~ ul li)

Regla aplicada: h3 ~ ul li { margin-bottom: 0.3rem; }
