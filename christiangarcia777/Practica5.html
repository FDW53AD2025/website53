Práctica 5: Selectores CSS

Utiliza esta página como guía para tomar las capturas de pantalla de los selectores aplicados a tu sitio web de pasatiempos. Cada sección te indica el código CSS, la ubicación del selector en tu sitio y un espacio para la captura.

1. Selector Universal (`*`)

Descripción: Aplica un estilo a **todos** los elementos de la página.

* {
    border: 1px dotted #ff0000;
}

Ubicación: Visible en **todas tus páginas** HTML. Fíjate en el borde punteado que rodea a cada elemento.

2. Selector de Tipo

Descripción: Aplica estilos a todos los elementos de un tipo específico (ej. h2, p).

h2, p {
    background-color: #f0f8ff;
}

Ubicación: Revisa cualquier página de tu sitio (ej. `inicio.html`). Los títulos `

` y párrafos `p` deberían tener un fondo de color claro.

3. Selector por ID

Descripción: Se usa para dar estilo a un **único** elemento con un ID específico.

#bienvenida {
    background-color: #e6f7ff;
    padding: 15px;
}

Ubicación: Se aplica al `div` con el `id="bienvenida"` en el archivo **`inicio.html`**. Debería tener un fondo y un borde especial.

4. Selector por Clase

Descripción: Aplica estilos a todos los elementos que tienen la misma clase.

.enlace-nav {
    font-weight: bold;
    color: #ffd700;
    text-decoration: underline;
}

Ubicación: Revisa la barra de navegación en **`inicio.html`**. Los enlaces con la clase `.enlace-nav` tienen un color y estilo de fuente distintos.

5. Selector de Atributo

Descripción: Selecciona elementos basándose en la presencia o el valor de un atributo.

input[required] {
    border: 2px solid #4CAF50;
}

Ubicación: En el formulario de contacto en **`inicio.html`**. Los campos con el atributo `required` tienen un borde específico.

6. Selector Hermano Adyacente (`+`)

Descripción: Selecciona un elemento que sigue **inmediatamente** a otro.

h2 + p.resaltado {
    background-color: #ffd700;
    padding: 5px;
}

Ubicación: En la página de **`VideoJuegos.html`**. El párrafo con la clase `.resaltado` que está justo después de un `

` tiene un fondo diferente.

7. Selector de Hermano General (`~`)

Descripción: Selecciona todos los elementos que son hermanos y que siguen a otro elemento.

h2 ~ p {
    font-style: italic;
    color: #555;
    border-bottom: 1px dashed #999;
    padding-bottom: 10px;
}

Ubicación: En la página de **`VideoJuegos.html`**. Todos los párrafos que siguen a un `

` tienen un estilo de fuente cursiva y borde.

8. Selector Descendiente (` `)

Descripción: Aplica estilos a un elemento que es descendiente de otro, sin importar el nivel de anidación.

.padre span {
    background-color: #90ee90;
    padding: 2px 5px;
}

Ubicación: En la página de **`SeriesYPeliculas.html`**. Fíjate en el `` dentro de la lista de curiosidades; tiene un fondo resaltado.

9. Selector Hijo Directo (`>`)

Descripción: Selecciona solo los elementos que son hijos **directos** de otro.

ul > li {
    list-style-type: square;
    color: #008080;
}

Ubicación: En la lista de curiosidades en **`SeriesYPeliculas.html`**. Solo los elementos de la lista principal tienen un estilo diferente de viñeta.

10. Selector de Lista (`,`)

Descripción: Permite agrupar varios selectores para aplicar el mismo estilo a todos ellos.

h1, h2, h3 {
    font-family: 'Georgia', serif;
}

Ubicación: En **todas tus páginas**. Los títulos `

`, `

` y `

` comparten la misma fuente, `Georgia`.
