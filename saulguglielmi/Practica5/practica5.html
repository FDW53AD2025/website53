Uso de Selectores

En esta parte de la pagina enseñaré las capturas de lo que se hizo con cada selector.

Nota: solo pondré los más relevantes (ya que son muchos).

Selector Universal

El selector universal (*) selecciona todos los elementos en el documento HTML. Se utiliza para aplicar un modelo de caja consistente (box-sizing: border-box;) y eliminar los márgenes y rellenos predeterminados de todos los elementos, asegurando que el diseño sea más predecible y uniforme.

Selector de Tipo

Los selectores de tipo se utilizan para aplicar estilos a todos los elementos de un tipo específico, como <body>, <h1>, <p>, etc. Se definen estilos base para el cuerpo del documento, encabezados y enlaces, que afectan la apariencia general de la página.

Selector de Clase

Los selectores de clase permiten aplicar estilos a elementos que comparten una clase común. Se definen clases como `.selector-card` y `.code-images` para aplicar estilos específicos a diferentes secciones y componentes de la página, lo que permite una mayor flexibilidad y reutilización de estilos.

Selector de ID

Los selectores de ID se utilizan para aplicar estilos a un elemento **único** en el documento que tiene un atributo id específico. Se definen estilos para un elemento, como `#header`, que afectan su apariencia sin influir en otros elementos.

Selector de Atributo

Los selectores de atributo permiten aplicar estilos a elementos basados en la presencia o el valor de un atributo específico. Se ha definido un estilo para los enlaces (a) que tienen el atributo target="_blank", lo que es útil para resaltar enlaces que abren en una nueva pestaña o ventana.

Selector de Pseudo-clase

Los selectores de pseudo-clase aplican estilos a elementos en estados específicos. En este caso, el selector :hover cambia el color y añade un efecto visual a los enlaces cuando el usuario pasa el cursor sobre ellos, mejorando la experiencia del usuario al proporcionar retroalimentación visual.

Selector de Descendiente

Los selectores de descendiente aplican estilos a elementos que están anidados dentro de otro. Por ejemplo, se define un estilo para los párrafos (p) que son descendientes de la sección principal (main), creando un margen inferior para mejorar la legibilidad y la apariencia visual del texto.

Selector de Hijo

Los selectores de hijo aplican estilos a elementos que son hijos directos de otro elemento. Por ejemplo, los elementos de la lista (li) que son hijos directos de una clase `.evidence-links` tienen un margen para crear espacio entre ellos, mejorando la legibilidad de la lista de enlaces.

Selector de Hermano General

Los selectores de hermano general aplican estilos a elementos que comparten el mismo padre. En este caso, se ha definido un estilo para los elementos <hr> que son hermanos de un elemento con la clase `.selector-card`, agregando un margen y un borde para separar visualmente las secciones y mejorar la organización de la página.
